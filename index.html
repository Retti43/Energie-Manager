Datensicherung und Übertragung

Alle Daten werden nur im Browser auf diesem Gerät gespeichert. Für den Austausch zwischen iPad und Windows exportierst du eine JSON-Datei und importierst sie auf dem anderen Gerät.

Achtung: Beim Import wird der vorhandene Datenbestand auf diesem Gerät ersetzt. Sichere ihn vorher. Browserdaten löschen, privates Surfen oder ein anderer Browser können den lokalen Speicher unzugänglich machen. Erstelle regelmäßig Sicherungsdateien.
